# Artwork and assets

The [approved Living Game Shelf reference](../images/redesign-reference.png) was option 2 in the design exploration. Its navy stage, coral play action, cream collection area, illustrated horizontal shelf and compact category/room controls ground the implementation.

- `redesign/public/art/game-worlds.png`: Adobe Firefly original artwork, generated for this milestone. Six illustrated family worlds, ordered Action / Board / Cards / Party / Puzzle / Word. Family artwork is intentionally shared by games in that family; it is an illustration rather than a gameplay screenshot.
- `redesign/public/art/tictactoe-hero.png`: Adobe Firefly original artwork for the first playable game's wide stage.
- `redesign/public/icons/`: existing Arcade branding and existing Tabler icons, copied from `assets/logo.svg` and `assets/icons/tabler/`. Existing attribution and licenses remain in [the credits](../credits.md).
- `docs/images/redesign-desktop.png` and `redesign-mobile.png`: captures of the actual built app, refreshed with the package capture script.

Connector assessment: Firefly produced cohesive tactile artwork and respected the six-panel arrangement. The atlas retained thin separators and the Word panel used warm wood instead of the requested green; CSS samples inside each panel. A separate wide hero avoids stretching a square family panel across a desktop stage. Assets were downloaded and visually inspected before integration. No external image host or runtime generation is used.
